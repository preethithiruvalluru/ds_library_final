## What can I do on this website?
keywords: website, portal, this website, this site, features, what is this, sections, how to use, how to use the website, how to use the portal, guide, overview, tour
questions: what is this portal | what can this website do | how do i use this site | what are the sections
starter: yes

This is the **Data Science Digital Library**, a study portal. Open the **menu** (the button at the top left) to visit:

- **Modules**: Module 1 to 5, each with study-material **PDFs** you read in a book-style viewer
- **Running Notes**: read and search class notes
- **Lab Experiments**: aim, code, output and result for each lab program
- **Tools**: data science tools with an official website and a **YouTube playlist** for each
- **Resources**: free and paid courses, W3Schools tutorials and YouTube videos
- **Code Editor**: write and run code (Python and JavaScript run right in your browser)

The round icon at the top right opens your **profile** (resume and student ID card). I can also answer questions about everything listed on these pages.

## How do I read the syllabus or study material PDFs?
keywords: syllabus, study material, read pdf, open pdf, view pdf, pdf viewer, book viewer, page flip, flip pages, how to read pdf, how to open pdf
questions: where is the syllabus | how to open a pdf | how to read study material | how do i view a pdf

Open **Modules** from the menu and click a module (for example *Module 1*). It opens a list of its PDFs. Press **View PDF** to open the **book-style reader**: flip pages with the arrows (or the left and right arrow keys, or by dragging a page corner), zoom in and out, go full screen, or download it. Press **Esc** or the red X to close.

If a module says there is no PDF yet, the study material has not been added to it.

## How do I run code in the Code Editor, and which languages work?
keywords: code editor, run code, editor, run python, run java, run javascript, run c, compile, output console, code runner, load code, monaco
questions: how to run code | which languages can i run | why is the run button disabled | java not running

Menu, then **Code Editor**. Pick a language, write code, type any input in the **Input** box (one value per line) and press **Run** (or Ctrl+Enter). **Stop** ends a running program and **Clear** empties the editor.

- **Python** and **JavaScript** run **inside your browser** (10 second limit, no network). The first Python run downloads the Python engine (about 10 MB), so it needs internet once.
- **Java, C and C++** run only when the separate **code runner** (needs Docker) is started on the computer hosting the portal. If the **Run** button is disabled for them, it is not set up there.
- **R and SQL** can be written but cannot be run yet.

## Do I need to log in? Who can change things?
keywords: login, log in, password, account, sign in, who can edit, permissions, security, no login
questions: is there a login | how to log in | who can delete my notes | is my data safe

There is **no login** in this portal. The pages are **view-only**, so visitors cannot add, edit or delete modules, notes, experiments, tools or resources. Only the profile can be edited with its **Edit** button, so only share the link with people you trust.

## How does this chat bot work? Does it use AI or the internet?

questions: are you ai | do you use the internet | how do you answer | how does the chatbot work | are you chatgpt

I am a **simple offline helper**, not an AI service. I compare the **words in your question** with a ready-made list of answers and with the content of this website (modules and PDFs, lab experiments, tools and resources), and reply with the best match. Nothing you type is sent anywhere outside this portal, and no API key is needed.

That means I only know what is written in my answer list and on the website. If I can't find your question, try different words, or ask a teacher.
